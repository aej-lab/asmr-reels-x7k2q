Privacy Policy

Last updated: 22 October 2026

ASMR Explains Uploader is a private tool that uploads videos to the ASMR Explains YouTube channel using the YouTube Data API. It is operated only by the owner of that channel.

Data we access

The tool accesses only the owner's own YouTube channel, solely to upload videos (the youtube.upload permission). It does not read, collect, store, sell or share personal data of any other person.

Authorisation tokens

The owner's OAuth credentials are stored as encrypted secrets in a private automation environment and are used only for uploads. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
